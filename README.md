# 🚗 자동차 경주
## ✒️ 과제 정리
1. 애플리케이션을 실행하면 안내 문구를 출력하고, 자동차 이름과 시도할 횟수를 입력받는다.
- 자동차 이름은 5자 이하만 가능하다.
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,)기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5
```
2. 쉼표(,)를 기준으로, 자동차 이름을 분리한다.
3. 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우 전진하고 4 미만일 경우 멈춘다.
4. 실행 결과 첫 출력시 '실행 결과'를 출력한다.
5. 시도 회차마다 움직인 결과를 이름과 함께 하이픈(-)으로 표시한다.
```
pobi : -
woni :
jun : -
```
6. 자동차 경주 게임을 완료하면 누가 우승했는지 출력한다.
- 우승자는 여러 명일 수 있으며, 쉼표를 이용하여 구분한다.
```
최종 우승자 : pobi, jun
```
7. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, [ERROR]로 시작하는 에러 메시지를 출력 후 그 부분부터 다시 받는다.
- 자동차 이름이 5자를 초과하는 경우
- 자동차 이름이 공백인 경우
- 시도할 횟수가 숫자가 아닌 경우

## 📝 구현할 기능 목록
### 입력 기능
- [ ] 자동차 이름 입력
- [ ] 시도할 횟수 입력

### 출력 기능
- [ ] 자동차 이름 입력을 위한 출력
- [ ] 시도할 횟수 입력을 위한 출력
- [ ] 실행 결과 출력
- [ ] 우승자 출력
- [ ] [ERROR] 메시지 출력
- [ ] 에러 이후 재입력

### 자동차 전진, 멈춤
- [ ] 무작위 값 생성
- [ ] 각 자동차의 무작위 값에 대한 전진, 멈춤 결정

### 우승자 결정
- [ ] 게임 완료 후, 누가 우승했는지 결정

### IllegalArgumentException 발생
- [ ] 자동차 이름이 공백이거나, 6자 이상인 경우
- [ ] 입력 받은 횟수가 숫자가 아닌 경우
